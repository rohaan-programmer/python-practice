# List and Dictionary Comprehensions Practice

This project contains Python scripts and data files demonstrating list and dictionary comprehensions in Python (CS50 Practice).

## 📄 Files Included:
- **`comprehesions.py`**: Python script that reads `address.txt`, counts word frequencies using dictionary comprehensions, and outputs data to `counts.csv`.
- **`address.txt`**: Source text file containing the input text data.
- **`counts.csv`**: Generated CSV file storing the calculated word frequencies.

## 🚀 How to Run
Run the Python script directly from the terminal:
```bash
python comprehesions.py
